CH 01
Introduction to CentOS Linux
Overview of Linux vs UNIX, the file system tree, partitions, and how to keep your system updated.
Key Concepts
  • CentOS is community-supported, RHEL-aligned
  • Linux = Kernel + Tools (utils, GUI, packages)
  • UNIX file system = tree starting at root /
  • Full path always begins with /
  • CentOS is open source (GPL)
Partitions
  • /boot — startup partition
  • swap — virtual memory
  • / — root: stores system & user data
Update Command
dnf update -y
Key Terms
CentOSCommunity Enterprise OS — community-supported, RHEL-aligned
RHELRed Hat Enterprise Linux
KernelCore that manages hardware and resources
Root /Top of the file system tree
PartitionDisk section for a specific purpose (e.g., /boot, swap)
File SystemFormat for storing files (e.g., ext4, xfs)
Quick Review
CentOS ↔ RHEL Linux = UNIX-based + GPL Tree starts at / /boot · swap · / dnf update -y

CH 03
Package Management
Managing software with dnf (repos) and rpm (.rpm files).
DNF Commands
Search & List
  • dnf search firefox
  • dnf list all
  • dnf list all | grep wget
  • dnf list installed
  • dnf list installed | grep wget
  • dnf list installed | grep -e wget -e firefox
Install / Remove
  • dnf install wget -y
  • dnf groupinstall "X Window System"
  • dnf localinstall file.rpm
  • dnf remove google-chrome
  • dnf update -y
RPM Commands
  • rpm -qa
    list all installed
  • rpm -qa | grep google
    find a package
  • rpm -ivh file.rpm
    install .rpm file
  • rpm -Uvh file.rpm
    update .rpm file
  • rpm -e <package>
    erase / remove
RPM Flags
-iInstall
-UUpdate
-vVerbose output
-hProgress hash marks
DNF Lock Fix

If dnf is locked (pid file error):

  • rm -rf /var/run/dnf.pid
  • dnf clean all
Remote RPM Install Example (Google Chrome)
  • wget https://dl.google.com/linux/direct/google-chrome-stable_current_x86_64.rpm
  • dnf localinstall google-chrome-stable_current_x86_64.rpm
Quick Review
dnf search <name> dnf install -y dnf update -y dnf remove dnf list installed rpm -qa rpm -ivh rpm -Uvh
CH 04
Files & Directories
Create, view, move, copy, delete files and directories. Master wildcards and find patterns.
cat — Create / View
  • cat > test1
    create interactively (Ctrl+Z to save)
  • cat test1
    view file
  • cat >> test1
    append (Ctrl+Z to end)
mv — Move / Rename
  • mv test1 test01
    rename file
  • mv test2 001/test2
    move file
  • mv test2 001/test3
    move + rename
rm — Delete ⚠ careful
  • rm <file>
    prompts before delete
  • rm -rf <file>
    no prompt, force
  • rm -rf f1 f2 f3
    multiple files
  • rm -rf *
    ⚠ EVERYTHING in folder
  • rm -rf test*
    starts with "test"
cp — Copy
  • cp file1.txt file2.txt
    copy file
  • cp -r apple/* test/
    copy all files from apple/ into test/
  • cp -r apple/. test/
    includes hidden files (.env etc.)
mkdir / rmdir
  • mkdir test1
  • mkdir t2 t3 t4
    multiple at once
  • rmdir test1
    remove EMPTY dir only
  • rm -rf test1
    remove non-empty dir
  • rm -rf test*
    wildcard on dirs
Find Patterns
find
Exact match
find test
Starts with
find test*
Contains
find *test*
Quick Review
mv old new cp a b cp -r dir1 dir2 mkdir name rmdir (empty) rm -rf (careful!) find *keyword*
CH 05
Users & Permissions
Manage user accounts, passwords, groups, and account security on CentOS.
Add / View Users
  • useradd username
    create user
  • passwd username
    assign password
  • cat /etc/passwd
    all user info
  • cut -d: -f1 /etc/passwd
    list usernames only (-f1 = first column)
Delete User ⚠
  • userdel -r username
    delete user + home dir
  • userdel username
    delete user only
  • rm -f /home/username
    manually remove home dir
Password Options
  • useradd username
  • passwd -d username
    create user WITHOUT password
  • chage -d 0 username
    force password change at next login
Lock / Unlock User
  • passwd -l username
    🔒 lock user
  • passwd -u username
    🔓 unlock user
Rename User
  • usermod -l ra makara2
    rename makara2 → ra (home dir keeps old name)
  • usermod -d /home/ra -m ra
    also rename home dir
Common issue: user process running
ps -u bora -o pid,cmd
kill 4363
Group Management
Groups — Create / View / Delete
  • groupadd IT01
    create group named IT01
  • cut -d: -f1 /etc/group
    list all group names
  • groups user1
    show groups of a user
  • lid -g group_name
    show all users in group
  • groupmod -n IT1 IT01
    rename group IT01 → IT1
  • groupdel IT1
    delete group
Add User to Group
  • useradd -g IT1 HAO
    new user HAO → group IT1
  • usermod -a -G IT2 Test1
    existing user Test1 → add to IT2
Flag meanings
-gSet primary group (new user)
-a -GAppend to supplementary group (existing)
-dDelimiter (e.g. in cut)
-fField/column (e.g. -f1 = first col)
Quick Review
useradd username passwd username userdel -r username passwd -l / -u chage -d 0 groupadd / groupdel usermod -a -G cat /etc/passwd
